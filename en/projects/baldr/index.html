Baldr

Status: Abandoned (since 2008)

Baldr, also known as Balder, is anti-plagiarism software.


Inspired by research in theoretical computer science, it compares documents using compression-related properties.

Developed within esiea-labs, the project is written in Java. It is therefore multi-platform.

For more information, I invite you to visit the project page on the esiea-labs site.
